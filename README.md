### 🚀 About Me

I am a **Backend Software Engineer** specialized in designing and building scalable, fault-tolerant distributed systems and microservices. My primary stack centers around **Go** and **Java (Spring Boot 3 / Java 21)**, with a deep focus on **Clean Architecture**, **Hexagonal Architecture (Ports & Adapters)**, **Domain-Driven Design (DDD)**, and **idiomatic Design & Concurrency Patterns**.

- 🔭 **Current Focus**: High-throughput distributed pipelines, event-driven architectures with Kafka & Redis, and lock-free concurrency in Go.
- 📐 **Software Philosophy**: SOLID principles, strict separation of concerns, test-driven reliability (Unit, Integration & Benchmarks), and clean, self-documenting code.
- ⚡ **Performance & Scalability**: Zero-allocation patterns, connection pooling, Redis caching strategies (Cache-Aside, Write-Through), and asynchronous worker pools.
- 🌐 **Looking for**: Senior / Mid-Senior Backend Engineer roles (Go / Java) building core backend platforms and distributed services.
